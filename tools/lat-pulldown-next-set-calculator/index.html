How Surpass chooses your next lat pulldown set

The calculator reads load, reps, and RIR, then applies lat pulldown-specific progression context. Pulldown progression depends on consistent torso angle, grip, and bottom position.

When to add weight

Add load when you hit the top of the target range at the planned RIR without changing the lat pulldown standard.

When to add reps instead

If the load jump is large or reps are still inside range, keep the same lat pulldown weight and add reps first.

Common mistake

Do not count heavier reps if the movement turns into a torso heave.

Examples

Short answers

What should I lift next for lat pulldown?

Use the smallest load jump when reps, RIR, and execution all support it. Otherwise add reps or hold load.

Why does RIR matter for lat pulldown?

RIR separates a repeatable progression signal from a set that only succeeded because effort spiked.

Method, assumptions, and privacy

Method

Uses reps plus RIR to estimate effective reps to failure, then applies rep-range progression rules: add load, add reps, hold, or reduce.

Assumptions

Best signal comes from recent sets in a stable rep range with consistent technique and a clear RIR estimate.

Privacy

Inputs are handled in the browser for the web tool experience. Surpass should only store lifting data when a user chooses to log it in the app.
