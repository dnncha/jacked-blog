# Author record template

Complete this template only for a real contributor.

```yaml
author:
  name: "REPLACE_WITH_REAL_NAME"
  role: "REPLACE_WITH_TRUTHFUL_ROLE"
  bio: "REPLACE_WITH_SHORT_FACTUAL_BIO"
  relevant_experience:
    - "REPLACE_WITH_VERIFIABLE_EXPERIENCE"
  profile_url: "REPLACE_WITH_PUBLIC_PROFILE_OR_REMOVE"
```

Do not publish the placeholder. Remove fields that cannot be supported.
