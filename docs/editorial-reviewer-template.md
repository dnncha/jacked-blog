# Reviewer record template

Complete this template only when a real reviewer has substantively reviewed the article.

```yaml
reviewer:
  name: "REPLACE_WITH_REAL_NAME"
  role: "REPLACE_WITH_TRUTHFUL_ROLE"
  relevant_experience: "REPLACE_WITH_VERIFIABLE_EXPERIENCE"
  reviewed_at: "YYYY-MM-DD"
  scope: "REPLACE_WITH_THE_PARTS_REVIEWED"
  profile_url: "REPLACE_WITH_PUBLIC_PROFILE_OR_REMOVE"
```

Do not imply clinical, coaching, scientific, or product credentials that have not been verified. Remove the reviewer field when no substantive review occurred.
